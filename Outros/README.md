# Análise de Dados - Fórmula 1

Este projeto contém uma análise exploratória de dados da Fórmula 1 de 2025.

## Objetivo
Investigar como fatores ambientais podem influenciar o desempenho nas corridas.

## Dados analisados
- Temperatura ambiente
- Umidade do ar
- Outras variáveis relacionadas às condições da corrida

## Ferramentas utilizadas
- Python
- Pandas
- Jupyter Notebook
- Análise exploratória de dados (EDA)

## Arquivos do projeto
- `Dados_primarios.ipynb` → notebook com a análise dos dados
- Arquivos `.R` → scripts adicionais de análise
- `.gitignore` → arquivos ignorados no repositório
